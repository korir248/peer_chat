## Local-first, serverless P2P chat for your network

peerChat is a desktop app that lets you chat with anyone on your local network without setup, servers, or internet.

![peerChat screenshot](screenshot.png)

## Features

- **Auto-discover** peers on your local network
- **Real-time messaging** with zero configuration
- **No servers** - truly peer-to-peer
- **No accounts, no tracking**
- **Works without internet**

## Alpha Status

## Download

Get the latest Windows release from [Releases](https://github.com/korir248/peer_chat/releases)

1. Download `.msi` or `.exe`
2. Install and run
3. Generate an alias
4. Chat with anyone on your network running peerChat

## Perfect for

- **LAN parties** - Chat without setting up a server
- **Small offices** - Internal communication that stays local
- **Internet outages** - Keep chatting when the WAN goes down
