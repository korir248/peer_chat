# Local Network Chat

peerChat automatically discovers anyone running the app on your local network using mDNS — no configuration needed.

## How it works

1. Launch peerChat
2. Anyone else on the same Wi-Fi or LAN running peerChat appears instantly in the **Nearby** sidebar
3. Click their name to start chatting

## Requirements

- Both devices must be on the same network
- No firewall blocking local traffic

## Notes

- Discovery is automatic and continuous — peers appear and disappear in real time as they join or leave the network
- No internet required
