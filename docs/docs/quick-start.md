# Quick Start

## 1. Set your alias

On first launch, set an alias — this is how others see you on the network.

## 2. Find nearby peers

Anyone running peerChat on your local network appears automatically in the sidebar under **Nearby**.

## 3. Start chatting

Click a peer to open a conversation and start sending messages.

## 4. Connect globally *(coming soon)*

Share your public key with anyone to connect directly across the internet.
