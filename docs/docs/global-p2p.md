# Global P2P Chat

::: warning Coming Soon
Global P2P chat by public key exchange is currently in development. This page documents the planned feature.
:::

## How it will work

1. Open peerChat and copy your public key
2. Share it with anyone — via Signal, email, in person, anywhere
3. They enter your public key in peerChat
4. A direct peer-to-peer connection is established
5. Chat directly with no server in the middle

## Why public keys

Your public key is your permanent identity in peerChat. No username, no phone number, no email — just a cryptographic key that is uniquely yours.

## Privacy

The connection is direct. No peerChat server is involved at any point. Not even for the initial handshake.
