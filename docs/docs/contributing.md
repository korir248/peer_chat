# Contributing

peerChat is open source under AGPL-3.0.

## Repo

[Github Repo](https://github.com/korir248/peer_chat)

## How to contribute

- Bug reports and feature requests via [GitHub Issues](https://github.com/korir248/peer_chat/issues)
- Pull requests welcome for the frontend and Tauri shell
- For questions, open a discussion on GitHub

## Note

The P2P networking layer is not part of the public repository.
